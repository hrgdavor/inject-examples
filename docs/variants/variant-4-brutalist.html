How it works

  1. 01Write a link A plain Markdown reference: file#path/fragment. No plugin, no build step.
  2. 02Run the CLI inject-examples your-doc.md fills every fenced block. One command, done.
  3. 03Gate it Strict mode: a broken reference is an error, not a warning. --lenient for drafts.
