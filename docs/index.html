How it works

  1. Write a link A plain Markdown reference: file#path/fragment. No plugin, no build step in your editor.
  2. Run the CLI inject-examples your-doc.md fills every fenced block with the live lines. One command, done.
  3. Gate it Strict mode is a gate: a broken reference is an error, not a warning. --lenient downgrades for drafts.
$inject-examples README.md
